## 一、测试设计

**案例**：「只有核显的轻薄本（无独显），想做本地 AI 视频」

**选它的理由**：与上次失败**完全同构**——共识说"不行"，但共识可能只是"可用性门槛"。

### 守则 A1：先验预注册（动手前写下，不可事后修改）

> **预期**：核显跑不了 AI 视频生成。
> **理由**：没有独立显存、共享 DDR 带宽低、算力不足。
> **我预期的答案**：「不可行，用云服务」。

## 二、结果：先验被推翻

### 决定性反例：[DARK-Shadw/ltx25-igpu-streaming](https://github.com/DARK-Shadw/ltx25-igpu-streaming)

| 项目 | 事实 |
|---|---|
| 硬件 | **Intel Core Ultra 5 125H 核显 + 15.6 GB 共享内存 + 无独显** |
| 跑的东西 | **完整未量化的 LTX-2.5（22B）视频+音频模型**（bf16，**零量化**） |
| 模型体积 | 磁盘上约 **66 GB** |
| 机制 | **从 NVMe 逐层流式加载权重**；预取线程在算第 n 层时读第 n+1 层，用计算掩盖磁盘 |
| 实测（同一个核显） | 5.4s / 1536×896 带音频 → **~14 分钟**<br>5s 最佳质量（真 24fps，3 步精修）→ **~47 分钟**<br>4s / 1280×704 写实 → ~20.6 分钟 |
| 依赖 | Windows · **~75GB 空闲磁盘（强建议 NVMe）** · ≥15GB 内存 |
| 活性 | **5★** · 创建于 **2026-10-09（3 天前）** · 未归档 |

> **一个普通核显，三天前，跑通了完整未量化的 22B 视频模型。**
> 而这模型"正常情况下要 40GB+ 显存"。

### 该仓库自己的「Honest limits」（按守则 C3 优先读）

- 快速/大幅的镜头或主体运动会糊掉或崩几帧；**慢速、克制的运动才干净**
- 动画按 12fps 生成、每帧显示两次；写实要 24fps，**耗时约翻倍**
- **人脸小于画面高度 ~25% 会糊**
- CUDA 路径**未在 NVIDIA 硬件上测试过**
- 其他 GPU 的速度是**估计值，不是实测**

**"Is not fast. A single clip takes minutes to an hour on this chip.
The point is that it runs *at all*."** ← 作者自己把可行性/可用性分得很清楚。

## 三、结论必须分档，不能说"行"或"不行"

核显不是一个东西。按守则 C2，必须把**可行性**和**可用性**分开，并按档位给：

| 核显档位 | 可行性 | 可用性 | 关键机制 |
|---|---|---|---|
| **AMD Strix Halo**（Ryzen AI Max+ 395 等） | ✅ 可行 | ✅ **较好**（可把 128GB 统一内存划给 iGPU） | 统一内存当显存 |
| **Intel Core Ultra / Arc 核显** | ✅ 可行 | ⚠️ 慢（5s ≈ 14–47 分钟） | NVMe 权重流式 + 预取 |
| **Apple Silicon** | ✅ 可行 | ⚠️ 慢 | MLX + streaming |
| **老 Intel UHD / 老 Vega 核显** | ❓ **本次未找到证据** | — | — |

**最保守的诚实表述**：
> 「核显**可以**跑，但这是可行性和可用性差距最大的场景之一。
> **会不会卡死，取决于磁盘（NVMe + 75GB 空闲）和内存，而不是显卡。**」

## 六、局限（诚实声明）

1. **不是独立测试**——守则是我写的，测试也是我跑的，存在确认偏误。
2. **B1 三类查询本次不是决定性的**：问题式查询同样返回了那个反例。
   真正起作用的是**先验预注册 + 不丢弃 + 分档**，不是查询式设计。**这条必须记下来，不要夸大机制。**
3. 单次测试，未重复。
4. **老核显（UHD / 老 Vega）没有找到证据**，该档位仍标 ❓。
5. 所有性能数字来自他人实测报告，未独立复现。

## 七、对守则的修订建议

基于第 2 条局限，守则应调整**权重**：

- **A1（先验预注册）应升到第一位** —— 它是唯一能让人"看见自己先验"的机制，
  而先验不可见是**所有其他失效的源头**
- **B2（不丢弃跨域命中）应升为强制条款** —— 本次和上次都栽在"按领域/按工具名过滤"
- **B1（三类查询）保留，但降级为"辅助"** —— 它有用，但不是决定性
- 新增：**「约束枚举必须包含磁盘和内存」** —— 本次硬门槛是 75GB NVMe，
  只问显卡会 100% 找不到答案

> ### 一句话修订
> **先把你的猜测写下来，然后专门去找它错在哪——并且不要因为"领域不同"就把答案扔掉。**
