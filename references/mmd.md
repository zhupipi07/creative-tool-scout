## 三、借物表格式细节 `[实测]`

### 三种格式与正则

```
格式 1（目标格式，信息量最大）
  ikClut_RC（滤镜）：RedialC/iKeno
  msUnsharp（锐化效果）：ましまし
  MotionBlur3（运动模糊）：そぼろ
  → ([A-Za-z][\w\-\.]{2,29})\s*[（(]([^）)]{1,14})[）)]\s*[：:]\s*(.+)

格式 2（工具与作者混在一起）
  MME：P.I.P/HAToon2/ExcellentShadow/化身バレッタ/角砂糖

格式 3（只有名字，切分靠猜）
  MME びーと/less./Caeru/鍵束/P.I.P
```

### 解析注意

- **区分作者名与工具名**：`そぼろ / ikeno / Rui / RedialC` 是**作者**；`ikClut_RC / msUnsharp / MotionBlur3 / HAToon2` 才是**工具**。两者对用户都有用，但要分开标注
- 常见字段：`模型 / Model / 动作 / Motion / MME / BGM / Stage / 镜头 / Camera / 场景 / 音乐 / 材质 / Shader / 渲染 / 软件`
- **简介有 250 字上限** → 作者会写「完整借物表见置顶评论」或「见上一个视频」
- 借物表可能跨行、含括号说明、用全角空格或 `|` 分隔
- **覆盖率 61.7%，但简单规则只能解析出 ~10%** —— 瓶颈在格式多样性，不在数据源
- **评论区不是工具名来源** `[实测]`：0/120 视频出现评论独有工具名

> ⚠️ **本节不提供工具清单。清单会腐烂，方法不会。**
> 下面给的是「**什么样的东西住在哪里、怎么认出来**」。

### 按类别找，不按名字找

| 类别 | 住在哪 | 怎么认出来 |
|---|---|---|
| **渲染器 / 主渲染** | 日本社区（BowlRoll、fanbox）· 借物表的「渲染」字段 | 通常是一整套**配置包**而不是单个文件；常见「XX 烤」的改版名 |
| **卡通渲染色 / 滤镜 / 后期效果** | 借物表的 `MME` 字段 · **VPVP wiki 的 MME 效果表** | **作者名常被当工具名用**；信息量最大的借物表会带上用途（滤镜 / 锐化 / 运动模糊） |
| **导入 / 格式转换** | GitHub · 各软件的扩展市场 | 名字里带格式（PMX / VRM / VMD）；**往往是别的软件的插件**，不是 MMD 本体 |
| **动作适配 / 骨骼处理** | GitHub · 贴吧与 CSDN 求助帖的解答 | 名字里带 `Sizing` / `Retarget` / `骨骼`；**低星但高收藏率**是典型特征 |
| **AI 辅助（动捕 / 文生动作）** | GitHub · B站「AI」标签 | 更新极快、名字里带 `AI` 或模型名 |
| **跨软件管线** | GitHub（多为个人项目） | 名字里带**两个**软件名（`MMD2UE5`、`Blender-MMD`）；**星标低、创建日期新** |

**识别信号**（比名字更可靠）：
- 借物表**格式 1**（`工具名（用途）：作者`）里出现的 = 创作者**实际用过**的
- 教程简介里推荐但借物表里没有的 = 可能只是听说过
- VPVP wiki 上有 `更新日` 和 `必要SM`（依赖）字段的 = 可信度高、能查依赖

### 四条技术路线（**这部分是方法，不是清单**）

```
1. MMD 原生 + MME        ← 教程最多，新手默认
2. Blender + mmd_tools   ← 更灵活，能做到 UE5 级渲染
3. UE5 / UE5.3           ← 存在完整 MMD→UE 管线
4. Houdini               ← 有"在 Houdini 里修 MMD 模型动作"的做法
```

**「路线的种类」比任何具体工具名都稳定。**
知道 2/3/4 **存在**本身就是价值——不同约束下的最优路线完全不同。

## 五、已知坑

### 渲染 / 材质

- **Blender 导入 PMX 后渲染模型泛紫** → 把所有材质的 `MMDShaderDev` 中的 `Toon Tex Fac` / 卡通纹理系数**改成 0** `[实测：抓自评论区]`
- 出图前把**色彩管理视图变换保持「标准」**——AgX / Filmic 会冲淡卡渲颜色

### 导入

- **PMX 导入 Blender 仅显示点** —— 高频报错，查 mmd_tools 版本与导入设置
- **PMX 导入 UE 后动作变形 / 骨骼错位** —— 需骨骼绑定与动画重定向
- 「模型导入后无法显示」是 MMD 最常见的求助标题 `[实测]`

### 物理 / 动作

- 自己绑物理流程漫长；素体容易造成关节扭曲
- 对比标准 TDA 模型，其他模型通常需要多 K 一些帧
- 衣物下摆乱飘是常见问题（布料解算）

### 版权与规约（**比技术更常踩**）

- 通用规约：**请勿二次配布、请勿商用、必须署名**
- **各种 MME 基本都是禁止二配的** —— 要让用户自行去配布地址获取 `[实测：借物表原文]`
- 恋活等提取的模型**不要配布、更不要收费配布**，即使自己改造过 `[实测：简介原文]`
- 网盘普遍设提取码；评论区常见"防删"写法（`pan.baidu.com` 中间插字）
